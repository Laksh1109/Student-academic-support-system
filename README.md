# Student Academic Support and Early-Intervention System

A role-based academic-support and early-intervention decision-support system
that helps faculty advisors identify students who may benefit from timely
academic support using educational data, statistical analysis and machine
learning.

## Project Overview

Faculty advisors may identify struggling students only after poor academic
outcomes or repeated missed work. This project provides an early
decision-support mechanism using academic and educational indicators.

The system provides separate views for students and authorised academic
advisors. Students can view their own academic progress, while advisors can
review relevant indicators, model predictions and support cases.

## Key Features

- Role-based student and advisor access
- Student academic progress dashboard
- Advisor dashboard
- Machine Learning-based support indicator
- Statistical analysis of academic factors
- Interactive data visualizations
- Support-case management
- Advisor follow-up and notes
- Human-in-the-loop decision making

the project. Its limited size and specific educational context will be
considered as a project limitation.
